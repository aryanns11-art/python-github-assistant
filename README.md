# 🤖 Python GitHub Assistant

A simple command-line GitHub Assistant chatbot built using Python.

It allows users to log in, ask Git and GitHub-related questions, receive predefined answers, and interact with a chatbot designed to help beginners learn version control concepts.

## 🚀 Features

* 🔐 User login authentication
* 💬 Interactive chatbot interface
* 📚 Answers common Git and GitHub questions
* 🎲 Random greeting responses
* 🚪 Logout functionality
* ❌ Exit commands to close the application
* 🖥️ Simple CLI-based interface

## 🛠️ Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* Random Module
* Dictionaries
* Lists
* Command Line Interface (CLI)
